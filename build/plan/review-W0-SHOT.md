- Before this unit, `--set` already leaked (HEAD set the autoload and PREDELETE saved it), but a flagless shot was a no-op rewrite of the loaded values. `reset_all()` turns EVERY shot into a rewrite with docs/13 defaults (+ the flags). W0-GATE's sheets run dozens of shots, so the developer's options are reset on every gate run.
- Fix, inside the owned file: before each `quit()` (or in a `_finalize()`), call `gs.call("load_from_disk")` so PREDELETE saves back exactly what the file held; then the header sentence becomes true.
